## Reflection

Using AI as a programming assistant helped me understand the development process more clearly, especially when working with Python environments, software testing, and GitHub.

Instead of relying only on AI-generated instructions, I performed the commands and tested the application myself. When errors occurred, I used the explanations to identify the causes and apply corrections.

This experience helped me improve my understanding of software development workflows, debugging, version control, and technical documentation.

I learned that AI is useful as a learning and problem-solving tool, but developers still need to verify the results and understand the code and commands they use.
